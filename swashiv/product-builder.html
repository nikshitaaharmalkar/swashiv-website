How to Publish This Product

  1. Fill in the photo, name, category and description above.
  2. Click Generate Code, then Copy Code.
  3. Open the shop.html file in a plain text editor (Notepad, TextEdit, or ask Claude to do this step for you).
  4. Find the line that says <!-- ADD NEW PRODUCTS ABOVE THIS LINE --> inside the product grid.
  5. Paste the copied code just above that line, then save the file.
  6. Go to your Netlify dashboard → your site → drag the whole updated project folder in again to republish. It takes about 10 seconds and instantly updates the live site.

Tip: you can also just send the generated code (or even just the photo, name, and description) to whoever manages the site for you, and they can paste it in for you in under a minute.
